Privacy Policy

Last updated: August 3, 2026

Earth Simulator is a climate exploration tool. This page explains exactly what information the app collects, where it goes, and what never leaves your browser. We have tried to write it in plain language.

What we collect — only with your consent

When you first visit, a banner asks whether we may record your session. If you accept, we collect a pseudonymous "session story" — a timeline of what you explored during this visit. Rows are stored in a Supabase table named telemetry_events. Each row has:

  • sessionId — a randomly generated ID for this visit only
  • timestamp — when the event occurred
  • event — the event type name (see table below)
  • payload — a small JSON object with the fields listed below

Chat text is never stored in full. For ordinary chat turns we store only a truncated preview (at most 80 characters) plus the structured command type and hazard event name returned by the parser. No full message text is written to the telemetry database.

Event types and payload shapes

These are the only event names and payload fields we write when you consent:

event payload
session_start { referrer, viewport } — referring page URL (if any) and browser window size (e.g. 1280x800)
session_end { totalEvents, durationMs } — count of events in the session and how long it lasted
chapter_change { year, ssp } — timeline chapter year and climate pathway
ssp_change { ssp } — climate pathway you selected
layer_change { layerId } — which map data layer you viewed
chat_query { textPreview, type, event } — truncated preview of your message (≤80 characters), parsed command type (e.g. climate_event, explain), and hazard event name if any (e.g. hurricane). Not the full message.
simulation_trigger { type, iso, event, year } — command type, country code if any, hazard event, and year from the command
support_shown { shown: true } only — a boolean flag that the crisis support message was displayed. Never includes message content.
support_offered { support_offered: true } only — a boolean flag that the short support footer was shown. Never includes message content.
region_click { iso } — country code you selected on the globe
region_dwell { iso, durationMs } — how long a country selection remained active
report_export { type, target } — export kind and country/target code if any

This data is used for one purpose: understanding what people are curious about so we can improve the simulator. It is not used for advertising and is not sold or shared.

If you decline

The app works exactly the same. Nothing is recorded for your session, and the banner will ask again on your next visit. Declining is stored only in your browser's memory for the current session.

What we do NOT collect

  • No account, name, email address, or phone number — there is nothing to sign up for.
  • No full chat message text in the telemetry database (only the ≤80-character preview described above, and never for support-path events).
  • No precise location. We never request your device's location.
  • No advertising trackers, no analytics cookies, no fingerprinting.
  • No cross-session profile: each visit gets a new random session ID, and session IDs are not linked to each other or to you.

What stays on your device

Chat history is never saved between visits — every reload starts a fresh conversation. The only thing the app stores in your browser is a single flag recording that you accepted the telemetry banner (so we don't ask again). If you decline, not even that is stored.

Third-party processing of chat messages

To understand your questions, the text you type into the chat is sent through our server-side proxy to Anthropic (the maker of the Claude language model), which processes it to generate the simulator's response. This happens regardless of your telemetry choice — it is how the chat works — but Anthropic receives only your chat messages from the current session (a rolling window of recent turns is included with each request so replies stay coherent) and scenario context (year, climate pathway), never a stored profile of you. That live API processing is separate from the telemetry database, which does not store full message text. See Anthropic's privacy policy.

Hosting and infrastructure

  • Netlify serves the app and, like any web host, processes your IP address in standard server logs.
  • Supabase hosts the telemetry database and the chat proxy. Our proxy uses your IP address transiently, in memory only, for rate limiting; it is not written to the telemetry database.
  • Cesium ion and NASA GIBS serve globe imagery and terrain tiles directly to your browser; those requests expose your IP address to them like any map-tile service.

Retention and deletion

Session stories are kept while we actively develop the simulator and are reviewed only by the operator. Because sessions are pseudonymous, we cannot identify which rows are yours after the fact; if you want a specific session removed, contact us with the approximate date and time of your visit and we will delete matching data.

Children

Earth Simulator is not intended for users under 13. We do not knowingly collect personal information from children; do not type personal details into the chat.

Changes

If this policy changes materially, the consent banner will reappear and ask again before any new collection begins.
