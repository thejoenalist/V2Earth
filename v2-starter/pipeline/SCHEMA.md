# Earth Simulator V2 — Baked Data Schema

All pipeline fetchers **must** write exactly these field names. `validate.py` enforces this schema after every bake.

---

## `public/data/climate.json`

Nested lookup: **ISO alpha-3 → chapter year → SSP pathway → metrics**.

```json
{
  "USA": {
    "2025": {
      "SSP2-4.5": {
        "temperature_anomaly_c": 1.1,
        "sea_level_rise_m": 0.08,
        "precipitation_change_pct": -2.4,
        "heat_days_gt35c": 18,
        "drought_index": 0.31,
        "exposed_population_pct": 0.04,
        "confidence": 0.91,
        "coverage_tier": "high"
      },
      "SSP5-8.5": { }
    },
    "2050": { },
    "2075": { },
    "2100": { }
  }
}
```

### Required chapters
`2025`, `2050`, `2075`, `2100`

### Required SSP pathways
`SSP2-4.5`, `SSP5-8.5`

### Field definitions

| Field | Type | Unit / range | Source |
|---|---|---|---|
| `temperature_anomaly_c` | `number \| null` | °C vs 1995–2014 baseline | CCKP CMIP6 `tas` anomaly |
| `sea_level_rise_m` | `number \| null` | metres above baseline | IPCC AR6 regional lookup |
| `precipitation_change_pct` | `number \| null` | % change vs baseline | CCKP CMIP6 `prpercnt` anomaly |
| `heat_days_gt35c` | `number \| null` | days per year | CCKP CMIP6 `hi35` climatology |
| `drought_index` | `number \| null` | 0.0–1.0 | Derived: `clamp(-precipitation_change_pct / 60, 0, 1)` |
| `exposed_population_pct` | `number \| null` | 0.0–1.0 | Derived from sea level + coastal classification |
| `confidence` | `number \| null` | 0.0–1.0 | 0.91 CMIP6 ensemble; 0.75 sea-level regional |
| `coverage_tier` | `string` | `high` \| `medium` \| `low` \| `sparse` | Derived from confidence |

### Coverage tier rules
- `confidence ≥ 0.8` → `high`
- `confidence ≥ 0.6` → `medium`
- `confidence ≥ 0.3` → `low`
- `confidence < 0.3` or all values `null` → `sparse`

Countries with no CCKP data: all metric fields `null`, `coverage_tier: "sparse"`, `confidence: null`.

## `public/data/worldbank.json`

Flat lookup: **ISO alpha-3 → socioeconomic indicators**.

```json
{
  "USA": {
    "population": 331000000,
    "gdp_usd": 23000000000000,
    "hdi": 0.921,
    "urban_pct": 82.7
  }
}
```

| Field | Type | Source |
|---|---|---|
| `population` | `number \| null` | World Bank `SP.POP.TOTL` |
| `gdp_usd` | `number \| null` | World Bank `NY.GDP.MKTP.CD` |
| `hdi` | `number \| null` | UNDP HDR composite indices CSV (`hdi_2022`) |
| `urban_pct` | `number \| null` | World Bank `SP.URB.TOTL.IN.ZS` |

Keys are always ISO alpha-3. World Bank API calls use ISO alpha-2 internally; fetchers convert via `iso_normalize.py`.

## `public/data/countries.geojson`

Natural Earth 110m admin-0 boundaries, stripped to minimal properties.

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "iso": "USA",
        "NAME": "United States of America",
        "CONTINENT": "North America",
        "REGION_UN": "Americas"
      },
      "geometry": { }
    }
  ]
}
```

| Property | Type | Notes |
|---|---|---|
| `iso` | `string` | ISO alpha-3 (renamed from `ISO_A3`) |
| `NAME` | `string` | Country name |
| `CONTINENT` | `string` | Natural Earth continent |
| `REGION_UN` | `string` | UN geographic region |

Features with unresolvable ISO codes (e.g. `-99`) are dropped with a pipeline warning.

## `public/data/attribution.json`

Required for CC BY 4.0 compliance. Generated by `build_attribution.py`.

```json
{
  "CMIP6": {
    "full_name": "Coupled Model Intercomparison Project Phase 6",
    "license": "CC BY 4.0",
    "citation": "Eyring et al. (2016), doi:10.5194/gmd-9-1937-2016",
    "accessed_via": "World Bank Climate Change Knowledge Portal",
    "url": "https://climateknowledgeportal.worldbank.org"
  }
}
```

Required top-level keys: `CMIP6`, `WorldBank`, `NaturalEarth`, `NOAA_LOCA2`.
